第一课

环境搭建：Python、Jupyter、PyTorch——一站式配齐

3 / 34

写AI代码之前，先搭好你的"工作台"。以下步骤在Windows和Mac上都适用。

安装Python（推荐3.10+版本）

去python.org下载最新版Python安装包。安装时勾选"Add Python to PATH"——这是最容易漏掉但最关键的一步。安装完成后，打开终端（Windows按Win+R输入cmd，Mac打开Terminal），输入 python --version，如果显示版本号，安装成功。

安装Jupyter Notebook——AI工程师的"草稿纸"

Jupyter是一种"交互式编程环境"——你可以一行一行写代码，即时看到每行的输出。对AI研究来说，这是最重要的工具：你可以边写边看数据长什么样、模型训练到哪一步了、哪里出错了。安装：在终端输入 pip install jupyter，然后 jupyter notebook 启动。

安装PyTorch——深度学习的主力框架

PyTorch是目前最流行的深度学习框架，几乎所有AI研究和教学都在用它。去pytorch.org，按照你自己的系统配置（Windows/Mac、有无GPU）选择对应的安装命令。有NVIDIA显卡选CUDA版本（训练速度快10-50倍），没有就选CPU版本（速度慢但也能跑）。安装命令形如：pip install torch torchvision torchaudio。

第二课

Python数据处理速成：NumPy + Pandas——AI工程师的左右手

7 / 34

在AI项目中，你80%的时间不是在写模型——而是在处理数据。NumPy和Pandas是你最高频使用的两个工具。

NumPy：一切AI计算的基石

NumPy的核心是ndarray——多维数组。所有AI模型的输入输出，本质上都是数字矩阵。NumPy让矩阵运算快到飞起（底层是C语言实现）。你需要掌握的基本操作：创建数组（np.array）、改变形状（reshape）、切片索引（arr[2:5]）、矩阵运算（np.dot做矩阵乘法）、统计函数（mean, std, sum）。就这些——不需要背，用到时查文档即可。

Pandas：表格数据的瑞士军刀

Pandas的核心是DataFrame——类似Excel表格的数据结构。绝大多数真实世界的数据都是表格形式（CSV、Excel、数据库查询结果）。Pandas让你轻松完成：读取数据（pd.read_csv）、查看数据概况（df.head(), df.describe()）、选择行列（df[列名], df.iloc[行号]）、筛选数据（df[df[列] > 100]）、处理缺失值（df.dropna()）、分组统计（df.groupby）。

MNIST数据集——"AI界的Hello World"

MNIST是7万张28x28像素的手写数字灰度图（0到9）。它是AI入门的标准数据集——够简单（每张图就784个像素）、但够真实（手写体有各种变体）。你的第一个神经网络的任务就是：看一张手写数字图，判断是0-9中的哪个数。

第四课

卷积神经网络（CNN）：图像分类实战——让AI"看懂"图片

20 / 34

全连接网络处理图像有一个致命缺陷：把图片展平成一维向量后，像素之间的空间关系全部丢失了——"左上角的像素"和"右下角的像素"在模型眼里没有区别。CNN解决了这个问题。

卷积核——"滑动的小窗口"

CNN的核心思想是一个小的滤波器（叫卷积核，通常是3x3或5x5像素）在图像上滑动，每次只看一个小区域。这个滑动操作叫"卷积"。卷积核学习提取某种特征——比如一个核学会检测水平边缘，另一个核学会检测竖条纹。多层卷积叠加：第一层检测边缘/纹理，第二层检测简单形状（圆形、角），第三层检测复杂部件（眼睛、轮子），更高层识别完整物体。

一个完整的CNN处理流程

输入图像（如32x32x3的RGB图片）→ 卷积层（提取特征）→ 激活函数ReLU → 池化层（缩小尺寸，保留重要信息）→ 重复"卷积+ReLU+池化"若干次 → 展平成一维 → 全连接层 → 输出分类结果。池化（Pooling）的作用是"降低分辨率"——取一个区域的最大值（Max Pooling）或平均值（Avg Pooling），在保留关键信息的同时减小数据量、加快计算。

第五课

模型调试与优化：学习率、正则化、数据增强——调参心法

26 / 34

写出第一个模型只是开始。让模型从"能用"到"好用"，靠的是调试和优化的技巧。

学习率（Learning Rate）——最重要的超参数

学习率决定每一步参数更新的大小。太大：训练不稳定，损失来回震荡甚至爆炸。太小：训练太慢，可能困在局部最优。标准做法：从0.001开始试，效果不好就减半或加倍。进阶工具：学习率调度器（lr_scheduler）——训练过程中自动调整学习率（如每10个epoch减半）。

正则化——防止"死记硬背"

Dropout：训练时随机"丢弃"一部分神经元（比如设dropout=0.5，每次前向传播随机关闭50%的神经元），强迫网络不依赖特定路径，学到更鲁棒的特征。注意：只在训练时开Dropout，测试/推理时要关掉。L2正则化（Weight Decay）：在损失函数中加一项"参数平方和"的惩罚——参数越大，惩罚越重，推动模型保持"简洁"而非"复杂"。

数据增强——"无成本扩充训练集"

对图像做随机翻转、旋转、裁剪、变色——每张图变成多张"不同的"图。这等于把训练集免费扩充了几倍到几十倍，而且让模型学会了"翻转后的猫还是猫"这种不变性。这是提升泛化能力最有效的手段之一，而且代码就几行。

第六课

综合项目：从0到1完成一个完整的AI项目

30 / 34

学到这里，你已经具备了独立完成AI项目的能力。这一课带你走完一个完整项目的全流程——每一步都是真实AI工程师的日常工作。

项目选题建议

选一个你感兴趣的问题，保证数据容易获取。推荐选题：猫狗分类（Kaggle Dogs vs Cats，简单经典）、手写汉字识别（中文字手写体，对中国用户有实际价值）、表情识别（FER2013数据集，7种表情分类）。

完整项目七步流程

1. 问题定义：你要解决什么问题？输入是什么（图片/文本/数值）？输出是什么（分类/回归/生成）？成功标准是什么（准确率>90%？）

2. 数据获取：从哪拿数据？Kaggle下载？自己收集？爬虫爬取？注意——没有数据，一切无从开始。

3. 数据探索与清洗：数据长什么样？有多少类？类别平衡吗？有缺失值吗？你需要"认识"你的数据。

31 / 34

4. 特征工程与预处理：原始数据→归一化→数据增强→划分训练/验证/测试集。

5. 建模：选择合适架构（图像用CNN，序列用RNN/Transformer），写出网络结构，设置损失函数和优化器。

6. 训练与调优：跑训练循环，观察loss曲线，调整学习率和正则化，直到验证集表现不再提升。

7. 评估与部署：在测试集上评估最终效果——准确率、精确率、召回率、F1。输出一份简洁的项目报告或用Gradio做一个在线demo。

项目复盘：问问自己

项目做完不是结束——复盘是能力提升最快的方式。问自己：哪个环节花时间最多？如果重做会怎么改进？学到了什么新东西？这个项目可以放进你的作品集——它在未来会比你想象的更有价值。
