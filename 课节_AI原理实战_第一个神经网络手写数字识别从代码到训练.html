现在来真的——用PyTorch构建一个能识别手写数字（MNIST数据集）的神经网络。不要被吓到，整个代码不到80行。

MNIST数据集——"AI界的Hello World"

MNIST是7万张28x28像素的手写数字灰度图（0到9）。它是AI入门的标准数据集——够简单（每张图就784个像素）、但够真实（手写体有各种变体）。你的第一个神经网络的任务就是：看一张手写数字图，判断是0-9中的哪个数。

完整代码骨架——逐块讲解

# 1. 导入库
import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
# 2. 准备数据（PyTorch自动下载MNIST）
transform = transforms.Compose([transforms.ToTensor()])

train_data = datasets.MNIST("./", train=True, download=True, transform=transform)

test_data = datasets.MNIST("./", train=False, transform=transform)

train_loader = DataLoader(train_data, batch_size=64, shuffle=True)

# 3. 定义网络：输入784像素 → 隐藏128神经元 → 隐藏64神经元 → 输出10类
class Net(nn.Module):
def __init__(self):

super().__init__()

self.fc = nn.Sequential(

nn.Linear(784, 128), nn.ReLU(),

nn.Linear(128, 64), nn.ReLU(),

nn.Linear(64, 10)

)

def forward(self, x):

return self.fc(x.view(x.size(0), -1))

# 4. 训练循环
model = Net()

criterion = nn.CrossEntropyLoss() # 损失函数

optimizer = optim.Adam(model.parameters(), lr=0.001)

for epoch in range(5):
for images, labels in train_loader:

optimizer.zero_grad() # 清空梯度

outputs = model(images) # 前向传播

loss = criterion(outputs, labels) # 算损失

loss.backward() # 反向传播

optimizer.step() # 更新参数

print(f"Epoch {epoch+1} 完成")

这个网络在几分钟内就能达到95%以上的准确率——你对一个从零写的"几乎最简单的神经网络"来说，这是惊人的成绩。把它跑通，你就从"了解AI"跨越到了"创造AI"。
